# Security Policy

## Dansk
- Rapporter sikkerhedshuller til **security@webjax.dk**.
- Del ikke exploit-kode offentligt før en fix er frigivet.
- Vi svarer inden for 5 hverdage og giver løbende status.

## English
- Report vulnerabilities to **security@webjax.dk**.
- Please use responsible disclosure and avoid public exploit details until a fix is released.
- We respond within 5 business days.

## Scope
- Nonce-verificering på formularer og AJAX-endpoints
- Input-sanitering og output-escaping
- Capability checks i admin-funktioner
- Prepared statements for database queries
- Rate-limiting for AJAX endpoints
- Ingen hardcoded secrets
- HTTPS (SSL/TLS) anbefales altid
