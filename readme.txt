CookieDK is a GDPR-compliant cookie consent plugin with Danish-first defaults.

== Description ==
CookieDK hjælper dig med samtykke-banner, cookie-detektion, logging og GDPR workflows.

== Installation ==
1. Upload plugin folder to `/wp-content/plugins/`.
2. Activate plugin.
3. Configure under Settings > CookieDK.

== FAQ ==
= Er pluginen klar til WordPress.org? =
Ja, version 1.0.0 indeholder tests, sikkerheds-checks og dokumentation.
