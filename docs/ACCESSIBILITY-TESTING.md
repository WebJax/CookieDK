# Accessibility Testing (WCAG 2.1 AA)

## Checklist
- Tastaturnavigation for alle knapper
- Fokusmarkering synlig
- ARIA labels på dialog og controls
- Kontrastforhold mindst AA

## Tools
- axe DevTools
- NVDA / JAWS / VoiceOver

## Keyboard
- Tab/Shift+Tab gennem banner og modal
- Escape lukker modal
