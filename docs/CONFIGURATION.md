# Configuration / Konfiguration

## Dansk
- Banner-position: top, bottom, side
- Farvetema og knapfarver
- Cookie policy URL
- Retention- og anonymiseringsindstillinger
- Cookie-katalog: daglig GitHub-sync af `cookies.json` / `providers.json`
- AI-beskrivelser via WordPress AI Client (Indstillinger → Connectors). Nye beskrivelser pushes til GitHub når et token er sat (`COOKIEDK_GITHUB_TOKEN` eller feltet GitHub-token)
