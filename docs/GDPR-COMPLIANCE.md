# GDPR Compliance

## Dansk
CookieDK implementerer:
- Data-minimering (kun nødvendige samtykke-data)
- Samtykkelogning med timestamp
- Data-export (DSAR)
- Sletning/revoke af samtykke
- IP-anonymisering efter retention-regler
- SSL/TLS anbefaling i drift

## English
CookieDK includes:
- Data minimization
- Consent logging
- DSAR export
- Consent revocation/erasure
- IP anonymization lifecycle
- SSL/TLS recommendation
