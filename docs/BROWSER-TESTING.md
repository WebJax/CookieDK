# Browser Testing Guide

## Browsere
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Mobile
- iOS Safari
- Android Chrome

## Responsiveness checklist
- Banner-positioner virker på 320px+ bredde
- Knapper er klikbare og læsbare
- Settings panel scroll/focus fungerer

## Performance
- Verificér ingen JS-errors
- Verificér få netværkskald ved samtykke
