# Installation / Installering

## Dansk
1. Upload plugin til `wp-content/plugins/cookiedk`.
2. Aktivér plugin i WordPress admin.
3. Gå til **Indstillinger > CookieDK**.

## English
1. Upload plugin to `wp-content/plugins/cookiedk`.
2. Activate it from WordPress admin.
3. Configure in **Settings > CookieDK**.
